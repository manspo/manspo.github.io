📝 Информация

  • ID генерируется из английского названия + год
  • При массовой загрузке название из имени файла
  • Порядок элементов — перетаскиванием
  • Код извлекается из имени файла
  • Поля для полной серии на продажу сохраняются в JSON
  • Дата добавления — когда фигурка добавлена в каталог
  • Дата выставления на продажу — отдельное поле forsale_date. Ставится автоматически при включении «В продаже», очищается при снятии галочки
  • При экспорте генерируются: stats.json, videos.json, forsale.json, collection.json, search.json
